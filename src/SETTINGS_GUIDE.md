# 用户设置页面使用指南

## 功能概述

用户设置页面提供了完整的账号管理和个性化设置功能，采用小红书风格的设计。

## 主要功能

### 1. 账号信息编辑 ✏️

用户可以编辑以下信息：
- **头像**：点击相机图标上传新头像
- **昵称**：修改显示名称
- **邮箱**：更新联系邮箱
- **个人简介**：添加或修改个人介绍

**编辑流程：**
1. 点击"编辑"按钮进入编辑模式
2. 修改需要更新的字段
3. 点击"保存"按钮保存更改
4. 或点击"取消"按钮放弃修改

### 2. 主题切换 🌓

支持浅色/深色模式切换：
- **浅色模式**：适合白天使用，眼睛更舒适
- **深色模式**：适合夜间使用，省电且护眼

切换方式：在偏好设置卡片中点击"深色模式"开关即可

### 3. 账号注销 🚪

安全退出当前账号：
1. 点击"退出登录"按钮
2. 确认对话框中点击"确认退出"
3. 系统将清除登录状态并返回上一页

## 技术实现

### 组件结构

```
/components/SettingsPage.tsx          # 设置页面主组件
/presentation/context/ThemeContext.tsx # 主题管理Context
```

### Context集成

设置页面使用了以下Context：
- `AuthContext`：用户认证和信息管理
- `ThemeContext`：主题切换管理
- `LanguageContext`：多语言支持

### DDD架构支持

- 使用 `updateProfile` 用例更新用户信息
- 通过 `User` 实体验证数据有效性
- 遵循领域驱动设计原则

## 访问路径

1. 进入个人主页（底部导航 "我的" 标签）
2. 点击右上角设置图标 ⚙️
3. 进入设置页面

## UI设计特点

- **小红书风格**：采用圆角卡片、渐变色彩
- **分组清晰**：账号信息、偏好设置、账号管理分别成组
- **视觉反馈**：编辑模式切换、保存状态提示
- **确认机制**：重要操作（如注销）有二次确认

## 主题切换效果

主题切换会影响以下元素：
- 背景色
- 文字颜色
- 卡片颜色
- 边框颜色
- 组件样式

主题设置会保存到 localStorage，下次访问时自动应用。

## 数据持久化

- 用户信息更新后即时保存
- 主题偏好保存到浏览器本地存储
- 语言设置跨会话保持

## 错误处理

- 表单验证：保存前验证必填字段
- 网络错误：提示用户重试
- 权限检查：确保只有登录用户可访问
